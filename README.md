# ⚡ ApexFolio — Ultra-Minimal Developer & Designer Portfolio

**ApexFolio** is a bespoke, typography-first, minimalist portfolio template engineered for software engineers, designers, and tech consultants who want to showcase their work with dignity and restraint.

Zero clunky dependencies. No AI buzzword gradients. Just pure, razor-sharp craftsmanship.

---

## 💎 Features

* **Refined Editorial Typography:** Clean hierarchy using `Inter` and `JetBrains Mono`.
* **Live Local Time:** Dynamic real-time clock showing your local timezone & contract availability.
* **Interactive Category Filtering:** Filter projects across Apps, Open Source, and Systems.
* **Interactive Case Study Modal:** Deep-dive modal drawer with architectural breakdown, metrics, and tech stack pills.
* **1-Click Copy Email:** Clean clipboard interaction with subtle tooltip feedback.
* **Responsive & Accessible:** Fully mobile-friendly, keyboard navigable (ESC to close modals).
* **Zero Build Step Required:** Plain HTML5, Tailwind CSS, and vanilla JavaScript. Edit and deploy instantly.

---

## 🛠️ Quick Customization Guide

### 1. Update Personal Info
Open `index.html` in your favorite code editor:
* Search for `Ahmed Abdelgawad` and replace with your name.
* Update the bio, location (`Cairo, EG`), and social media links.
* In `assets/js/main.js`, update `emailToCopy = 'your.email@example.com'`.

### 2. Update Projects & Case Studies
* In `index.html`, project cards have clear `data-category` tags (`fullstack`, `oss`, `systems`).
* In `assets/js/main.js`, edit the `caseStudies` object to add your real project details, metrics, and links.

### 3. Deploy for Free
* **GitHub Pages:** Push to GitHub and enable Pages in repository settings.
* **Vercel / Netlify:** Drag and drop this folder directly into Vercel or Netlify.
